Install

macOS

Apple Silicon, macOS 14 or later. With Homebrew:

brew install --cask Route23/tap/dopamine

From the .dmg: the app is not notarized, so run this once before the first launch.

xattr -dr com.apple.quarantine /Applications/dopamine.app

Windows

Windows 10 or 11, x64 or ARM64. Run the installer — it installs for your user only, no administrator rights.

The installer is not code-signed yet. If SmartScreen says “Windows protected your PC”, choose More info, then Run anyway.

Dopamine updates itself on both systems.
